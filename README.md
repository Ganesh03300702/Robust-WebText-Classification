# Robust Web Text Classification Using Transformer Ensemble

## Overview

This project develops a Transformer-based ensemble framework for multi-class
web text classification using BERT, RoBERTa, DistilBERT, and DeBERTa.

The project evaluates individual Transformer models and combines their
predictions using ensemble learning techniques to improve classification
robustness. It also investigates prediction confidence using temperature
scaling and Expected Calibration Error (ECE).

## Problem Statement

Single Transformer models can produce different predictions for the same text.
This project investigates whether combining multiple Transformer models can
provide more robust classification performance.

The system focuses on four-class AG News classification:

- World
- Sports
- Business
- Sci/Tech

## Objectives

- Fine-tune Transformer models for text classification.
- Compare BERT, RoBERTa, DistilBERT, and DeBERTa.
- Combine model predictions using ensemble methods.
- Evaluate soft and hard voting strategies.
- Implement stacking-based meta-learning.
- Evaluate prediction confidence calibration using temperature scaling.
- Analyze classification performance using accuracy and macro F1-score.

## Models Used

| Model | Purpose |
|---|---|
| BERT | Base Transformer classifier |
| RoBERTa | Robust Transformer classifier |
| DistilBERT | Lightweight Transformer classifier |
| DeBERTa | Enhanced Transformer classifier |

## Ensemble Methods

### Soft Voting

The logits generated by the four Transformer models are averaged and the class
with the highest combined score is selected as the final prediction.

### Hard Voting

Each model produces a class prediction and the final class is selected using
majority voting.

### Stacking

The logits generated by the individual Transformer models are combined and
used as input features for a Logistic Regression meta-learner.

## Confidence Calibration

Temperature scaling is implemented to evaluate prediction confidence.

The project compares:

- Accuracy before and after calibration
- Negative Log-Likelihood (NLL)
- Expected Calibration Error (ECE)

The goal is to determine whether the predicted confidence better reflects
actual model performance.

## Data Processing

The preprocessing pipeline includes text cleaning operations such as:

- HTML removal
- URL removal
- whitespace normalization
- text normalization
- Transformer tokenization

## Evaluation Metrics

The models and ensemble methods are evaluated using:

- Accuracy
- Macro F1-score
- Negative Log-Likelihood (NLL)
- Expected Calibration Error (ECE)
